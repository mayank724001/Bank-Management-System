# Bank Management System

A simple **Bank Management System** developed using Python and Tkinter. This project provides a graphical interface to perform basic banking operations such as creating an account, depositing money, withdrawing money and viewing transaction history.

The main purpose of this project is to understand GUI development in Python and learn how different banking operations can be implemented using functions and basic programming concepts.

## Features

- **Create Account:** Create a bank account using customer details.
- **Deposit Money:** Add money to the account balance.
- **Withdraw Money:** Withdraw money with balance validation.
- **Transaction History:** View previous account transactions.
- **Account Report:** Check account details, current balance and transaction summary.
- **Input Validation:** Handles invalid inputs and insufficient balance.
- **User-Friendly Interface:** Simple banking dashboard with a clean design.

## Technologies Used

- **Programming Language:** Python
- **GUI Library:** Tkinter
- **Date and Time:** Datetime module

## How to Run the Project

**Step 1:** Make sure Python is installed on your computer.

**Step 2:** Clone this repository.

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 3:** Open the project folder.

```bash
cd Bank-Management-System
```

**Step 4:** Run the Python file.

```bash
python bank.py
```

The Bank Management System window will open.

## Limitations

- Account information is stored temporarily in program memory.
- Data is lost when the application is closed.
- Only one account can be created during a program session.
- This project does not connect to any real banking system.
